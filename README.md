# Linear Regression from Scratch

Linear Regression implemented from scratch using its mathematical formulas, with Python, NumPy and matplotlib.
No machine learning library (like scikit-learn) is used for the model itself.

## What it does
- Implements the Linear Regression formulas step by step with NumPy
- Plots the data and the fitted line using matplotlib

## Tech used
Python, NumPy, matplotlib, Jupyter Notebook

## Files
- `linear_regression_scratch.ipynb`: the full implementation with outputs

## How to run
1. Install the libraries: `pip install numpy matplotlib notebook`
2. Run `jupyter notebook` and open `linear_regression_scratch.ipynb`
3. Click Kernel > Restart & Run All
